# План проекта: сайт автосервиса

## 1. Цель проекта

Сделать сайт автосервиса под ключ: быстрый, понятный, SEO-готовый, с формами заявок и калькулятором стоимости ТО на базе Google Sheets + Apps Script без отдельного backend на первом этапе.

Главная бизнес-цель: получать заявки на запись в сервис и давать пользователю быстрый расчет стоимости обслуживания по марке и модели автомобиля.

## 2. Основные функции

### 2.1. Лиды и запись

- Формы заявки на сайте: имя, телефон, автомобиль, услуга, комментарий.
- Отправка заявки в групповой Telegram-чат через Telegram Bot API.
- Антиспам-защита: honeypot-поле, ограничение частоты отправки, валидация телефона.
- События аналитики: отправка формы, клик по телефону, клик по мессенджерам, открытие калькулятора.

### 2.2. Калькулятор стоимости ТО

- Пользователь выбирает марку, модель, поколение/двигатель при необходимости.
- Сайт получает данные из Google Sheets через опубликованный Apps Script endpoint.
- На первом этапе без backend: схема сайт -> Apps Script -> Google Sheets -> сайт.
- Кеширование ответа на клиенте, чтобы снизить нагрузку и ускорить повторные запросы.
- Отдельное состояние ошибки: если таблица недоступна, показываем понятный fallback и предлагаем оставить заявку.

### 2.3. Контент и доверие

- Главный экран: понятное позиционирование, география, ключевая услуга, CTA.
- Блоки услуг: ТО, диагностика, ремонт, обслуживание конкретных систем.
- Галереи пространства сервиса и работ.
- Блок команды/мастеров.
- Отзывы, гарантии, контакты, карта, режим работы.
- Страницы/секции под SEO-запросы по услугам и маркам автомобилей.

## 3. SEO-стратегия

### 3.1. Базовая структура

Минимальная структура на старт:

- `/` — главная страница автосервиса.
- `/services/` — список услуг.
- `/services/technical-maintenance/` — техническое обслуживание.
- `/services/diagnostics/` — диагностика.
- `/prices/` — цены и калькулятор ТО.
- `/contacts/` — контакты, карта, схема проезда.
- `/about/` — о сервисе, команда, оборудование.

Дальше можно расширять посадочными страницами:

- `/services/oil-change/`
- `/services/brake-service/`
- `/services/suspension-repair/`
- `/cars/bmw/`
- `/cars/mercedes/`
- `/cars/audi/`

### 3.2. Что важно для локального SEO

- Указать город/район в title, H1, тексте и контактах.
- Добавить NAP-данные: название, адрес, телефон в едином формате.
- Подключить schema.org: AutoRepair, LocalBusiness, PostalAddress, OpeningHoursSpecification, AggregateRating при наличии отзывов.
- Настроить `robots.txt`, `sitemap.xml`, canonical URL.
- Добавить Open Graph и корректные meta title/description.
- Подготовить Google Business Profile / Яндекс Бизнес, если еще не настроены.

### 3.3. Контентные приоритеты

- Сначала коммерческие страницы услуг.
- Затем страницы под марки автомобилей.
- Потом информационные статьи: интервалы ТО, признаки неисправностей, подготовка к сезону.

## 4. Техническая архитектура MVP

### 4.1. Frontend

Рекомендуемый стек:

- Vite + React или Next.js, если планируем много SEO-страниц.
- Для SEO предпочтительнее Next.js или Astro, потому что страницы можно отдавать статически.
- Если сайт компактный и основной упор на скорость запуска, можно оставить чистый HTML/CSS/JS или Vite.

### 4.2. Telegram-лиды

Безопасный вариант: не хранить токен бота в frontend.

Варианты:

1. Apps Script endpoint принимает заявку и отправляет ее в Telegram.
2. Serverless function на Vercel/Netlify принимает заявку и отправляет ее в Telegram.
3. Временный вариант только для теста: прямой вызов Telegram из frontend не рекомендуется, потому что токен будет открыт.

Рекомендация для MVP: Apps Script для Telegram-заявок тоже подходит, если backend пока не планируется.

### 4.3. Google Sheets + Apps Script

Рекомендуемая структура таблицы:

| brand | model | generation | engine | service_type | mileage | price | parts | labor | comment |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| BMW | 3 Series | F30 | 2.0 | ТО | 10000 | 15000 | 9000 | 6000 | пример |

Apps Script должен отдавать JSON:

```json
{
  "updatedAt": "2026-09-23T00:00:00Z",
  "items": []
}
```

Для производительности лучше отдавать все справочники одним ответом, если данных мало.

## 5. Аналитика

На старте подключить:

- Google Analytics 4 или Яндекс Метрику.
- Цели: отправка формы, клик по телефону, клик Telegram/WhatsApp, расчет стоимости ТО.
- UTM-метки для рекламы и постов.
- Call tracking можно добавить позже, если пойдет платный трафик.

## 6. Этапы работ

### Этап 1. Подготовка

- Загрузить текущий дизайн/исходники в репозиторий.
- Разобрать текущую структуру сайта.
- Зафиксировать стек и способ деплоя.
- Составить список страниц и блоков.

### Этап 2. Доработка дизайна

- Уточнить первый экран и CTA.
- Сделать структуру блоков более продающей.
- Доработать мобильную версию.
- Проверить галереи, анимации, формы, калькулятор.

### Этап 3. Интеграции

- Настроить Google Sheets.
- Написать Apps Script API для калькулятора.
- Написать Apps Script/API для Telegram-заявок.
- Проверить ошибки, лимиты и fallback-сценарии.

### Этап 4. SEO и запуск

- Настроить метатеги, sitemap, robots, schema.org.
- Оптимизировать скорость загрузки и изображения.
- Подключить аналитику.
- Проверить индексацию, адаптивность, формы.
- Выпустить первую версию.

### Этап 5. Развитие

- Добавить посадочные страницы под услуги.
- Добавить посадочные страницы под марки авто.
- Подключить отзывы и кейсы.
- Улучшить калькулятор и воронку записи.

## 7. Риски и решения

| Риск | Что может случиться | Решение |
| --- | --- | --- |
| Apps Script лимиты | При росте трафика API может тормозить или упираться в лимиты | Кешировать данные, позже вынести в backend/serverless |
| Открытый Telegram token | Если отправлять из frontend, токен украдут | Отправлять только через Apps Script/serverless |
| Плохая SEO-индексация | SPA без статических страниц может хуже индексироваться | Использовать статическую генерацию или SSR |
| Медленная загрузка | Видео и фото могут утяжелить сайт | WebP/AVIF, lazy loading, сжатие видео |
| Мусорные заявки | Спам через формы | Honeypot, rate limit, валидация, captcha при необходимости |

## 8. Ближайшие действия

1. Загрузить текущие файлы сайта в репозиторий.
2. Проверить структуру проекта и выбрать финальный стек.
3. Составить карту страниц и SEO-ядро для первой версии.
4. Подготовить структуру Google Sheet для калькулятора.
5. Настроить Telegram bot и тестовый групповой чат.
6. Реализовать формы и калькулятор.
7. Провести технический SEO-аудит перед публикацией.
