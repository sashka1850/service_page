# Genesis Team Service

Самостоятельный сайт автосервиса Hyundai, Kia и Genesis. HTML, CSS и модульный JavaScript, без конструктора, сборки, CDN и сторонних библиотек. Это первая переработанная версия исходного наброска, а не пиксельная копия Tilda.

## Локальный запуск

Требуется Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://localhost:8000. Двойной клик по index.html не подходит из-за модулей JavaScript. Если установлен Node.js, доступны `npm start` и `npm test`. Установка npm-пакетов не нужна.

## Где редактировать

- `index.html` — секции и основной текст, метаданные.
- `src/styles.css` — оформление и адаптивная версия.
- `src/data.js` — услуги, команда, цены, контакты и путь к видео.
- `src/app.js` — калькулятор, мобильное меню и контакты.
- `assets/` — локальные временные фотографии; происхождение в SOURCES.md.

Изображения сотрудников и фоновое изображение — заглушки из исходного сайта, не подтверждение личности или реального вида сервиса. Замените файлы под теми же именами либо измените пути. Фоновое видео подключается через `config.heroVideo` в src/data.js; при ошибке или предпочтении уменьшенного движения остаётся фото. Старое видео намеренно не перенесено.

## Что уже работает

- Адаптивные разделы услуг, диагностики, пространства, команды и вопросов.
- Калькулятор для девяти моделей; смена марки сбрасывает модель и цену.
- Переход к контактам с выбранной услугой/автомобилем.
- Телефон и Telegram появляются после заполнения валидных значений в config.
- Мобильное меню, клавиатурный фокус и поддержка reduced motion.

## До публичного запуска

- [ ] Уточнить номер дома: в исходнике указаны и 52б, и 52д.
- [ ] Заполнить реальный телефон, Telegram, режим работы.
- [ ] Подтвердить цены, состав ТО, применимость к двигателям/годам/пробегам.
- [ ] Заменить временные фото и подтвердить права на материалы.
- [ ] Подтвердить должности, стаж и сертификаты команды; добавить доказательства.
- [ ] Согласовать реальные условия гарантии, добавить отзывы и примеры ремонтов.
- [ ] Выбрать приём заявок: телефон/мессенджер либо отдельный серверный обработчик.
- [ ] Для формы с персональными данными подготовить необходимые тексты и обработку данных.
- [ ] Выбрать хостинг/домен; проверить сайт на реальных телефонах.

**Отправки заявки пока нет.** Сайт не собирает телефон и не показывает ложный успех. Выбор услуги только переносится в контакты; цены обозначены как предварительные. Секреты будущих интеграций хранятся на сервере, не в src/data.js.

## Размещение

Подойдёт любой статический веб-сервер. Все пути относительные — сайт можно размещать и в подпапке `/service_page/`. Развёртывание и GitHub Pages в этом проекте не включены автоматически.
