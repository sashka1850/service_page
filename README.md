# Genesis Team Service

## Калькулятор ТО через Google Таблицы

Калькулятор читает только подтверждённые строки (`статус = готово`) из двух листов: `Лист1` (автомобили) и `Лист2` (цены). Названия столбцов должны совпадать с текущим файлом «База цен на ТО (1).xlsx». Пустые строки под данными допустимы. Посетитель выбирает марку, модель, вариант автомобиля и вид ТО. Сайт получает цену и `price_id` по `model_id` и `вид_ТО`. Кнопка «Записаться» открывает форму обратного звонка с выбранной услугой.

1. Откройте **ту Google Таблицу, в которой лежат данные**, выберите «Расширения → Apps Script». Вставьте код из [`apps-script/Code.gs`](apps-script/Code.gs) и сохраните проект.
2. Разверните как **веб-приложение**: выполнять от имени владельца, доступ — «Все». Скопируйте URL опубликованного развёртывания, оканчивающийся на `/exec`. Сама Google Таблица остаётся закрытой, но опубликованные цены и каталог доступны посетителям сайта.
3. В [`src/data.js`](src/data.js) укажите URL в `config.maintenanceApiUrl`, затем выполните `npm run build` и опубликуйте обновлённый сайт. В репозиторий следует сохранить также обновлённый `src/site.js`: именно он подключён на странице.
4. Проверьте на сайте выбор нескольких моделей и ТО. При изменении данных таблицы каталог обновится в течение пяти минут благодаря кешированию.

По текущему файлу 44 варианта автомобиля и 440 цен со статусом «готово» доступны для калькулятора. Пять вариантов с ценами «проверить» не публикуются. Если позднее появятся одинаковые подписи автомобиля для разных `model_id` или повтор одного вида ТО для модели, такие неоднозначные записи автоматически исключаются до исправления. Адрес Apps Script нельзя использовать как секрет или ограничение доступа; этот API отдаёт только каталог и цены.

### Форма обратного звонка и Telegram

Форма требует имя, российский телефон и согласие на обработку персональных данных. Имя, телефон и ID выбранной цены отправляются **POST-запросом** в Apps Script. Скрипт повторно проверяет ID и берёт актуальную цену из таблицы, затем отправляет сообщение в чат через Telegram Bot API. При ошибке сообщение об успехе не показывается. В форме «Позвонить» включится только после указания подтверждённого номера сервиса.

1. В Apps Script замените прежний код на новую версию [`apps-script/Code.gs`](apps-script/Code.gs). В настройках проекта → **Свойства скрипта** добавьте `TELEGRAM_BOT_TOKEN` (токен бота) и `TELEGRAM_CHAT_ID` (ID чата, в который добавлен бот с правом отправлять сообщения). Не добавляйте эти значения в GitHub, Google Таблицу или `src/data.js`.
2. Разверните **новую версию существующего веб-приложения**: «Развернуть → Управление развертываниями → Изменить → Версия: новая». Оставьте прежний адрес `/exec`, выполнение от владельца и публичный доступ. При первом вызове Apps Script может запросить у владельца разрешение на отправку HTTP-запросов.
3. Укажите настоящий номер в `config.phone` в [`src/data.js`](src/data.js), например в формате `+79991234567`. Если политика обработки данных опубликована, укажите её HTTPS-адрес в `config.privacyPolicyUrl`. Выполните `npm run build` и опубликуйте сайт.
4. Проверьте заявку с тестовыми контактными данными, получение сообщения в нужном чате и состояние ошибки при неправильных настройках бота. Браузерное подтверждение доставки требуется после развертывания; локальные тесты не отправляют сообщения в Telegram.

Самостоятельный сайт автосервиса Hyundai, Kia и Genesis. HTML, CSS и JavaScript, без конструктора, CDN и сторонних библиотек. Это первая переработанная версия исходного наброска, а не пиксельная копия Tilda.

## Локальный запуск

Для быстрого просмотра полностью распакуйте ZIP и откройте `index.html` двойным кликом. Папки `src` и `assets` должны лежать рядом с ним. Не открывайте HTML прямо внутри архива.

Для просмотра через локальный сервер можно использовать Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://localhost:8000. Прямое открытие index.html также поддерживается готовым файлом src/site.js. Если установлен Node.js, доступны `npm start` и `npm test`. Установка npm-пакетов не нужна. После изменения src/data.js или src/app.js выполните `npm run build`, чтобы обновить src/site.js.

## Где редактировать

- `index.html` — секции и основной текст, метаданные.
- `src/styles.css` — оформление и адаптивная версия.
- `src/data.js` — услуги, команда, цены, контакты и путь к видео.
- `src/app.js` — калькулятор, мобильное меню и контакты.
- `assets/` — локальные временные фотографии; происхождение в SOURCES.md.

Изображения сотрудников и фоновое изображение — заглушки из исходного сайта, не подтверждение личности или реального вида сервиса. Замените файлы под теми же именами либо измените пути. Фоновое видео подключается через `config.heroVideo` в src/data.js; при ошибке или предпочтении уменьшенного движения остаётся фото. Старое видео намеренно не перенесено.

## Что уже работает

- Адаптивные разделы услуг, диагностики, пространства, команды и вопросов.
- Калькулятор по Google Таблице; смена марки сбрасывает модель, вариант, вид ТО и цену.
- Форма обратного звонка для выбранного автомобиля и ТО; лид отправляется после настройки Telegram и обновления Apps Script.
- Телефон и Telegram появляются после заполнения валидных значений в config.
- Мобильное меню, клавиатурный фокус и поддержка reduced motion.

## Размещение

Подойдёт любой статический веб-сервер. Все пути относительные — сайт можно размещать и в подпапке `/service_page/`. Развёртывание и GitHub Pages в этом проекте не включены автоматически.

## Фотоальбомы пространства сервиса

В `src/data.js` массив `spaceAlbums` содержит три независимых альбома: сервисный центр, клиентская зона, ремонтная зона. Добавьте снимки в `assets/`, затем добавьте записи `{ src: './assets/имя.jpg', alt: 'Описание фотографии' }` в нужный альбом. Стрелки, точки и счётчик появляются автоматически при наличии двух и более фото. Поддерживаются свайпы и клавиши ←/→ при фокусе на кнопках альбома.

В первом альбоме представлены три имеющиеся зоны. У клиентской и ремонтной зоны пока по одному предоставленному изображению: дополнительные снимки нужно добавить, они не подменены фотографиями чужих зон.

## Альбомы сотрудников

В `team` у каждого сотрудника есть `photos`: первый кадр — портрет, второй — сертификат. Сейчас это графические заглушки с явной маркировкой. Для замены добавьте `src: './assets/имя-файла.jpg'` и корректный `alt` в нужный объект. Сохраните `kind: 'certificate'` у документа, чтобы он отображался целиком без обрезки. Свайп, стрелки и точки работают независимо в каждой карточке.

Фото в блоках пространства и команды открываются по нажатию в увеличенном просмотре. Доступны стрелки, свайпы, Escape, закрытие по фону, возврат фокуса в карточку. Фото и сертификаты показываются целиком.

## Фоновое видео

На первом экране подключено assets/service_zone.mp4 из предоставленного видео. Веб-копия без звука, H.264, 60 FPS, исходная продолжительность. Автовоспроизведение и цикл. hero.jpg остаётся резервным фоном при запрете автозапуска или включённом уменьшении движения. Исходное видео не изменено.

В миниатюрах блоков 04/05 стрелки убраны: доступны свайп, перетаскивание мышью, точки и клавиши ←/→. В увеличенном просмотре стрелки сохранены. Карточки услуг плавно поднимаются на 8 px при наведении, с учётом настройки уменьшения движения.

Перелистывание внутри карточек анимировано горизонтальным сдвигом (380 мс), в направлении жеста. Быстрые повторные переключения отменяют предыдущий переход; настройка уменьшения движения отключает анимацию.
