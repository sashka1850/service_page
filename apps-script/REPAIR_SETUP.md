# Подключение расчета ремонта

1. В той же Google Таблице, к которой привязан текущий Apps Script, должны быть листы `Работы` и `Настройки` из согласованного файла.
2. На листе `Работы` первая строка содержит заголовки `work_id`, `Наименование`, `Седан, нч`, `Кроссовер, нч`, `Внедорожник, нч`. Колонки цен можно оставить: API считает цену из норматива и ставки. Колонка `active` не нужна.
3. На листе `Настройки` в колонке A находится `Стоимость нормочаса, ₽/нч`, в B той же строки — числовая ставка. Строки `sedan`, `crossover`, `suv` в A содержат русские названия классов в B. Строка `Подсказка поиска` задает текст под полем работы.
4. Откройте «Расширения → Apps Script». Замените содержимое существующего `Code.gs` полным содержимым файла `apps-script/Code.gs` из этой ветки. Не создавайте второй файл с дублирующими `doGet` / `doPost`.
5. Сохраните и обновите существующее развертывание: «Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть». URL `/exec` должен остаться прежним. Свойства Telegram сохраняются.
6. Откройте текущий URL `/exec?action=version`: ожидается `2026-10-04.1`. Затем `/exec?action=repairCatalog`: ожидается `ok: true`, три класса и 17 работ (или актуальное количество строк).
7. После успешной проверки API опубликуйте изменения сайта из ветки `feat/repair-calculator`. Если создано новое развертывание с другим URL, сначала обновите `maintenanceApiUrl` в `src/data.js` и выполните `npm run build`.

Каталог загружается один раз при первом открытии вкладки ремонта и хранится в памяти страницы. Поиск и смена класса не обращаются к API. При сбое доступна повторная загрузка. Для получения измененных цен нужно обновить страницу. При отправке заявки API читает таблицу заново и отклоняет заявку, если цена изменилась.

Поиск проверяет все слова запроса в любом порядке, допускает части слов, не различает регистр и е/ё. Синонимы и расшифровки сокращений автоматически не добавляются. Пустой норматив означает, что работа для этого класса недоступна; ноль означает нулевую трудоемкость. Дубликаты ID и ошибки формул возвращают ошибку каталога.

Проверка после публикации: открыть ремонт, выбрать каждый класс, найти работу по фрагментам в обратном порядке, проверить цену и данные в форме записи. Переключиться на ТО и проверить прежний расчет. Реальную тестовую заявку отправлять только в согласованный тестовый чат.
